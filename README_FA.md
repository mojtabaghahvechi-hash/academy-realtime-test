# نسخهٔ آزمایشی منشی فارسی با 1xAI Realtime

این پروژه یک نمونهٔ اولیهٔ وب است که از مرورگر موبایل، میکروفون را می‌گیرد و با مدل `gpt-realtime-mini` از طریق WebSocket سرویس 1xAI مکالمه می‌کند.

## نکتهٔ امنیتی
کلید اصلی `1xai-...` را هرگز در HTML، JavaScript، چت یا مرورگر وارد نکنید. کلید فقط باید در فایل `.env` روی سرور قرار بگیرد. مرورگر فقط یک client secret کوتاه‌عمر دریافت می‌کند.

## اجرای محلی برای توسعه
1. Python 3.10 یا جدیدتر نصب باشد.
2. در پوشهٔ پروژه:
   ```bash
   python -m venv .venv
   ```
   ویندوز:
   ```powershell
   .venv\Scripts\activate
   ```
   لینوکس/macOS:
   ```bash
   source .venv/bin/activate
   ```
3. نصب وابستگی‌ها:
   ```bash
   pip install -r requirements.txt
   ```
4. فایل `.env.example` را به `.env` تغییر نام دهید و کلید واقعی 1xAI را در مقدار `ONEXAI_API_KEY` قرار دهید.
5. اجرا:
   ```bash
   uvicorn app:app --host 127.0.0.1 --port 8000
   ```
6. در همان کامپیوتر `http://127.0.0.1:8000` را باز کنید.

## انتشار برای تست روی گوشی
برای دسترسی از گوشی باید این برنامه روی یک میزبان HTTPS اجرا شود؛ دسترسی میکروفون در مرورگر موبایل معمولاً به HTTPS یا localhost نیاز دارد. متغیر محیطی `ONEXAI_API_KEY` را در تنظیمات امن میزبان تعریف کنید و هرگز فایل `.env` را در مخزن عمومی آپلود نکنید.

## محدودیت‌ها و مواردی که باید در تست بررسی شوند
- این نسخه برای نمونهٔ اولیه است، نه سرویس تولیدی.
- صفحه فعلاً احراز هویت، محدودیت مصرف، گزارش هزینه و حفاظت در برابر استفادهٔ عمومی ندارد؛ آن را عمومی منتشر نکنید.
- کیفیت صدای فارسی، انتخاب صدای خروجی، تشخیص پایان نوبت و سازگاری مرورگر اندروید باید عملاً آزمایش شوند.
- اتصال 1xAI طبق مستندات از WebSocket استفاده می‌کند؛ مدت هر نشست و اعتبار client secret محدود است.
- برای جلوگیری از هزینهٔ ناخواسته، فقط پس از آماده‌سازی محدودیت مصرف و دسترسی، آن را در اینترنت عمومی منتشر کنید.


## انتشار رایگان روی Render
1. فایل ZIP را روی رایانه باز کنید و محتویات را در یک مخزن خصوصی GitHub قرار دهید.
2. در Render گزینه New > Blueprint را بزنید و مخزن GitHub را متصل کنید.
3. Render فایل `render.yaml` را می‌خواند و سرویس Free را می‌سازد.
4. در بخش Environment سه مقدار محرمانه را وارد کنید: `ONEXAI_API_KEY`، `TEST_USERNAME` و `TEST_PASSWORD`.
5. پس از Deploy، آدرس HTTPS با دامنه `onrender.com` نمایش داده می‌شود. هنگام باز کردن صفحه، مرورگر نام کاربری و رمز تست را می‌پرسد.

Render Free بعد از ۱۵ دقیقه بی‌ترافیکی سرویس را خاموش می‌کند و بیدار شدن دوباره ممکن است حدود یک دقیقه طول بکشد. برای تست کوتاه مناسب است، اما برای منشی واقعی و تماس‌های ورودی مناسب نیست.
